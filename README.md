# Rui Zhu Portfolio — V4

A static HTML/CSS/JavaScript portfolio site using GSAP, ScrollTrigger, and Lenis.

## Preview locally

Open this folder in VS Code and use the Live Server extension on `index.html`.

You can also run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Main files

- `index.html` — page content and links
- `styles.css` — layout, typography, light/dark themes, responsive styling
- `script.js` — opening animation, smooth scrolling, journey interactions, project/dance motion, video modal
- `assets/images/` — portfolio imagery
- `assets/docs/` — resume and public documents

## Publishing

This is a static site and can be deployed directly with GitHub Pages, Netlify, or Vercel.
